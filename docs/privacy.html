Privacy Policy

YT Transcript Yoinker · Last updated September 22, 2026 · No data collected

TL;DR: We collect nothing. This extension does not collect, store, or send any personal data anywhere.

Data Collection

YT Transcript Yoinker collects zero data. No personal information, no browsing history, no analytics, no cookies, no trackers, no accounts.

How it Works

  • When you are on a YouTube video page, the extension checks if a transcript exists.
  • It adds a "Copy Transcript" button to the page.
  • When you click it, it reads the transcript text that YouTube already loaded on the page.
  • It copies that text to your clipboard using navigator.clipboard.writeText().
  • Nothing is sent to any server. Everything happens locally on your device.

Permissions

  • activeTab — To read the transcript from the current YouTube tab only.
  • clipboardWrite — To copy the transcript to your clipboard. We never read your clipboard.
  • youtube.com — To add the button only on YouTube. The extension does not run on other websites.

Third Parties

No data is shared with any third party. There are no third-party SDKs, no external APIs, and no servers. We don't have a server to send data to. (want to send data to us? buy us a server lol )

Children's Privacy

Since we collect no data, we have no data about children either.

Changes

If this policy changes, we will update this page. We intend to keep this extension with no data collection.
